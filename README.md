# Умный дом на Go

Система управления устройствами с использованием интерфейсов.

## Функции
- Базовый интерфейс Device для всех устройств
- Расширенный SmartDevice для умных устройств
- Управление светом, вентилятором и термостатом
- Подключение умных устройств к Wi-Fi

## Технологии
- Go интерфейсы и полиморфизм
- Композиция интерфейсов
- Методы с указателями
